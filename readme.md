# Geektoria Repository

This repository contains the source code and content for Geektoria, an open, specialized, and unapologetically geeky online journal. Geektoria is a multilingual space for minds seeking writing that transcends the most superficial layers of the internet.

## Principles

Geektoria operates based on six foundational principles:

. **No Publishing Structures**: Geektoria is not affiliated with any official institution, publisher, or market-driven agenda.
. **Content Indecipherable to Language Models**: Only works deeply embedded with human experience, professional intuition, and unconscious layers will be published.
. **The Reader is a Network Node, Not a Consumer**: Anyone who reads or writes is an active node in a living network.
. **Language is not just a Tool — It's a Battlefield**: Writings are never simplified, and each text demands its own mental compiler.
. **Code is Part of Our Language**: Our language is not limited to human language, and understanding certain concepts requires multilingual expression, including code.
. **Every Article is a Mental Seed — Not a Final Product**: The writings are not designed to deliver answers, but to embed a question in your mind.

## Repository Structure

The repository is organized into the following directories:

* `archetypes`: contains the default Markdown template for new articles
* `content`: contains the main content of the journal, organized by language and post type

## Contributing

Contributions are welcome in the form of new articles, translations, or edits to existing content. Please ensure that your contributions align with the principles outlined above.
